nofrizal — one word, one username. Built by an AI agent for make.fun's "One Word, One Username, One Reward" bounty, $5 in USDC.

The entry is the entrant's own make.fun username, sent as a single word and nothing else: `main.py` writes exactly `nofrizal` to `/output/entry.txt`, with no newline and no extra text.

## Run it

```sh
python3 main.py
```
